# Animated Flowers 🌸

![Animated Flowers Preview](assets/preview.png)

A visually stunning, CSS-driven animation project featuring blooming flowers in a serene night garden. This project demonstrates the power of modern CSS animations, gradients, and 3D transformations to create a rich, interactive experience without heavy scripting.

## 🌟 Features

- **Pure CSS Animations**: Realistic blooming effects and swaying motions using `@keyframes`.
- **3D Perspective**: Utilizes CSS `perspective` for a sense of depth and realism.
- **Dynamic Lighting**: Interactive glow and light particles that simulate a magical night atmosphere.
- **Responsive Design**: Scalable visual elements using `vmin` units to ensure a consistent look across different screen sizes.

## 🚀 Getting Started

### Prerequisites
All you need is a modern web browser (Chrome, Firefox, Safari, or Edge).

### Running the Project
1. Clone the repository:
   ```bash
   git clone https://github.com/rajjitlai/Animated_Flowers.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Animated_Flowers
   ```
3. Open `index.html` in your browser:
   - On Windows: `start index.html`
   - On macOS: `open index.html`
   - On Linux: `xdg-open index.html`

Alternatively, you can simply double-click the `index.html` file in your file explorer.

## 🛠️ Built With

- **HTML5**: For the structural layout of the flowers and garden elements.
- **CSS3**: Leveraging advanced animations, radial/linear gradients, and transformations.
- **JavaScript**: A minimal script used to trigger the entry animations once the page is fully loaded.
